# ADR-0001: Миграция локальной таблицы Passes на схему v2

- **Статус:** Accepted
- **Вариант:** 12

## Контекст
Локальная SQLite БД АРМ хранит проходы в `Passes`. Требуется добавить точку доступа и статус прохода, сохранив исторические записи.

## Решение
Добавить:
- `AccessPoint TEXT NOT NULL DEFAULT 'UNKNOWN'`;
- `Status TEXT NOT NULL DEFAULT 'Active'`.

Версия схемы хранится в `PRAGMA user_version`. Перед изменением создается backup. Изменение таблицы и версии выполняется в транзакции. После миграции проверяются версия, новые поля и количество строк. При ошибке файл восстанавливается из backup.

## Последствия
Плюсы: воспроизводимая миграция, контроль версии, резервная копия и автоматическая проверка.

Ограничения: учебная реализация рассчитана на локальный файл SQLite. Перед копированием/миграцией нужно остановить процессы записи. Для парка АРМ необходим центральный оркестратор и проверка подписей пакетов.

## Альтернативы
Ручное изменение таблицы менее воспроизводимо. Пересоздание таблицы повышает риск потери данных.
