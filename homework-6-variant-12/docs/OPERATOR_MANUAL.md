# Руководство оператора АРМ «Умный кампус»

## Назначение
АРМ оператора используется для работы с локальной базой данных проходов. `CampusDbSync` — техническая утилита администратора, а не пользовательская программа.

## Вход
1. Войдите в Windows под выданной учетной записью.
2. Запустите основное приложение АРМ штатным ярлыком.
3. Авторизуйтесь средствами ИС «Умный кампус».
4. Не передавайте пароль другим сотрудникам.

## Основные операции
- Просматривайте список проходов.
- Проверяйте дату, время, идентификатор пользователя и точку доступа.
- При расхождении данных не редактируйте SQLite вручную.

## Действия при сбоях

| Ситуация | Действие |
|---|---|
| АРМ не запускается | Записать текст ошибки и время, сообщить администратору |
| Нет связи с сервером | Сообщить ответственному, не менять сетевые настройки |
| Не отображаются проходы | Не удалять локальную БД и не очищать каталог данных |
| Ошибка после обновления | Прекратить работу и дождаться администратора |

Оператор не запускает миграцию и не восстанавливает резервные копии самостоятельно.
